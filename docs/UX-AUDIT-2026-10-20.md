# Mobile & interaction audit — 2026-10-20

Scope: the live site (`gramshiksha-academy.vercel.app`), every role, desktop and
the iPhone 13 / iPhone SE viewports, plus a local seeded full stack for flows
that write data. Read-only checks ran against production; writes (enrollment,
lesson completion, notes, quizzes, uploads, approvals, invitations) ran locally
so production data stayed clean.

## Findings and fixes

| Finding | Cause | Fix |
| --- | --- | --- |
| 6 px horizontal page scroll on the public home/login screens at 320–390 px | `.hero-home` used a hard-coded `-20px` side margin while `main.container` drops to 14 px padding at ≤480 px | `main.container` now exposes `--page-pad` (20 px, 14 px at ≤480) and the hero uses `calc(-1 * var(--page-pad))` |
| 47 px overflow on the teacher dashboard at 320 px | "Students needing help" table was not scroll-contained | wrapped in the same `.table-scroll` region used by the admin dashboard (focusable, labelled) |
| "Why this book" input spilled out of its card on mobile | `gridColumn: 'span 2'` forced a second column in a one-column `auto-fit` grid | `gridColumn: '1 / -1'` spans whatever columns exist |
| Admin/teacher deep links such as `#/dashboard` and `#/progress` rendered student pages and produced 403s | the route switch had no role gate; the sidebar hid the links but bookmarks/history still reached them | role-scoped pages now redirect to the account's own home (student → dashboard, parent → parent, teacher/school admin → teacher, platform admin → admin); anonymous visitors go to the matching login page |
| Anonymous `#/parent` / `#/admin` landed on a login page that rejects those roles | redirect reused the student/teacher designated login | parent and admin now go to the generic `#/login` entry point |

The materials authoring form and its layout were left untouched as required.

  material upload (auto-approved), student-upload approval.

- Parent: invitation creation, parent sign-up, invitation acceptance, child
  stats ("Student linked: Priya Sharma").
- Admin: login, user list, approve/suspend teacher, course assignment,
  announcement.
- Registration through the modal stores class/board/language and opens the
  library pre-filtered (`Class 5`, `CBSE`, Hindi).

  0 px overflow at 320 px.
